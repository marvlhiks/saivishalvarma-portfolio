# Gaming covers (optional)

The tiles on /experience are original artwork drawn in code
(components/InterestArt.tsx), so nothing copyrighted ships in this repo.

If you want a real image instead, drop a file here named after the entry key
from data/interests.ts and it takes over automatically:

  rdr2.jpg
  clairobscur.jpg
  skyrim.jpg
  assassins.jpg

Formats: .jpg .jpeg .png .webp .avif

Only use images you own or are licensed to publish. Publisher key art and logos
are usually neither.
