# Photography

Drop image files straight into this folder. They appear on /experience under
"Off the clock" and open in the lightbox. Nothing else to update.

- Formats: .jpg .jpeg .png .webp .avif
- Order: filename, sorted naturally. Prefix with 01- 02- to control it.
- Captions: derived from the filename (golden-hour-lyon.jpg -> "Golden hour lyon").
  For something better, add an entry to the `captions` map in lib/photos.ts.

The .md file here is ignored by the loader.
